# M4X Theme v3.0.9 - In-app Update

- Tự kiểm tra `update.json` khi mở ứng dụng.
- Hồ sơ > Cập nhật ứng dụng > Kiểm tra cập nhật.
- Tải APK bằng DownloadManager và mở màn hình cài đặt Android.
- Hỗ trợ cập nhật bắt buộc bằng `forceUpdate: true`.

## Cấu hình online
Sửa file `update.json` ở thư mục gốc và bảo đảm GitHub Pages triển khai file này.
`apkUrl` phải là link HTTPS tải trực tiếp file APK.
