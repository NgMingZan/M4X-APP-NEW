# M4X Theme v3.0.5

- Admin có thể thay tối đa 5 ảnh xem trước của theme đã đăng.
- Ảnh mới được upload lên Supabase Storage và cập nhật ngay vào bảng themes.
- Người dùng mở hoặc làm mới danh sách sẽ thấy ảnh mới, không cần cập nhật dữ liệu thủ công.
- Tính năng quản trị này cần cài APK v3.0.5 một lần; sau đó mọi lần sửa ảnh/theme đều cập nhật online.
