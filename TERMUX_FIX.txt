M4X Arena Online v3.4.0 — FIX REALTIME 401

Lỗi:
Expected HTTP 101 response but was '401 Unauthorized'

Nguyên nhân:
ArenaOnline.kt gửi Authorization header trong WebSocket handshake.
Bản sửa chỉ gửi SUPABASE_ANON_KEY trong query parameter và gửi
session JWT sau bằng phx_join/access_token.

Cài patch:

cd ~/storage/downloads
unzip -o M4X_ARENA_REALTIME_401_FIX.zip

cp -a M4X_ARENA_REALTIME_401_FIX/. ~/storage/downloads/M4X-APP-NEW-RUST/

cd ~/storage/downloads/M4X-APP-NEW-RUST
git add app/src/main/java/com/m4xtheme/app/ArenaOnline.kt
git commit -m "Fix Supabase Realtime WebSocket 401"
git push origin main

Không cần chạy lại SQL Supabase.

Nếu bản mới vẫn báo 401:
GitHub → repository → Settings → Secrets and variables → Actions
Kiểm tra SUPABASE_ANON_KEY phải là anon key hoặc publishable key
đúng của cùng dự án với SUPABASE_URL.
