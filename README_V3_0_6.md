# M4X Theme v3.0.6

- Top đóng góp tuần tính từ theme được duyệt, lượt tải hợp lệ và thời gian dùng app.
- Thời gian dùng app tối đa 120 phút/ngày.
- Mở Rương M4X tốn 20 coin, giải tối đa 3.500 coin.
- Giải dương thấp nhất 10 coin; có kết quả 0 coin “Chúc bạn may mắn lần sau”.
- Slogan: “Cờ bạc là bác thằng bần”.

Trước khi build APK, chạy `SUPABASE_V3_0_6_CONTRIBUTION_CHEST.sql` trong Supabase SQL Editor.
