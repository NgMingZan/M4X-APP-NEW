# M4X Theme v3.8.2 — Theme Detail Flow

## Thay đổi
- Thẻ theme ngoài trang chủ không còn nút Mua/Tải trực tiếp.
- Nút ngoài danh sách đổi thành Xem chi tiết.
- Mua/Tải chỉ xuất hiện trong trang chi tiết theme.
- Trang chi tiết hiển thị ảnh, mô tả, danh mục, phiên bản hệ điều hành,
  đánh giá, lượt tải, điểm an toàn, trạng thái SHA-256 và số dư M4X Coin.
- Ghi nhận lượt xem khi người dùng mở chi tiết.
- Không cần SQL mới.
