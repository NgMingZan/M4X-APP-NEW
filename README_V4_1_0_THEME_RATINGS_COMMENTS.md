# M4X Theme v4.1.0 — Theme Ratings & Comments

## Chức năng mới

- Mỗi theme có điểm đánh giá từ 1 đến 5 sao.
- Hiển thị điểm trung bình và tổng số lượt đánh giá.
- Người đã mua hoặc nhận theme mới được đánh giá.
- Mỗi tài khoản có một đánh giá cho mỗi theme.
- Người dùng có thể sửa số sao và bình luận cũ.
- Bình luận tối đa 600 ký tự.
- Danh sách hiển thị tên, ảnh đại diện, số sao và thời gian.
- Admin/Super Admin có thể ẩn hoặc hiện lại bình luận vi phạm.
- Điểm `themes.rating` tự cập nhật sau khi gửi hoặc kiểm duyệt.

## Cài đặt

1. Chạy `SUPABASE_V4_1_0_THEME_RATINGS_COMMENTS.sql`.
2. Chép patch v4.1.0 vào dự án.
3. Build APK bằng GitHub Actions.
