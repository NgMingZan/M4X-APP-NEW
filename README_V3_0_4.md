# M4X Theme v3.0.4

- Nhiệm vụ đã nhận thưởng tự ẩn khỏi danh sách.
- Lỗi nhận lại nhiệm vụ/Giftcode được đổi thành thông báo tiếng Việt dễ hiểu.
- Airdrop chuyển thành rương xuất hiện ngẫu nhiên trong lúc sử dụng app.
- Admin xem và chỉnh sửa mọi theme: tên, mô tả, link Drive, giá coin và trạng thái.
- Upload theme chỉ dùng schema mới `owner_id` + `title`, không còn cột cũ `author`/`name`.
