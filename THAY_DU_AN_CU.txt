CÁCH THAY DỰ ÁN CŨ TRÊN TERMUX

1. Giải nén file ZIP mới vào Download.
2. Sao lưu hoặc xóa nội dung thư mục m4x_actions cũ, nhưng giữ thư mục .git.
3. Sao chép toàn bộ file mới vào m4x_actions.
4. Chạy:

cd /storage/emulated/0/Download/m4x_actions
git add -A
git commit -m "Replace with clean M4X project"
git push

GitHub Actions sẽ tự chạy sau khi push.
