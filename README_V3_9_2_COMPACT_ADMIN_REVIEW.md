# M4X Theme v3.9.2 — Compact Admin Review

## Đã rút gọn phần Admin

Trước đây mỗi theme luôn hiện:

- ảnh lớn
- thông tin Rust
- báo cáo an toàn
- năm dòng checklist
- các nút duyệt và từ chối

Bản mới chỉ hiển thị:

- ảnh thu nhỏ
- tên và giá
- trạng thái Rust
- điểm an toàn
- tiến độ checklist
- nút **Kiểm duyệt**

Bấm **Kiểm duyệt** mới mở ảnh lớn, báo cáo an toàn, checklist,
nút Duyệt và Từ chối.
