# M4X Theme v3.8.0 — Hệ thống kiểm duyệt nâng cao

## Tính năng
- Checklist 5 mục bắt buộc trước khi duyệt.
- Lịch sử: người duyệt, thời gian, kết quả, checklist và lý do.
- Super Admin xem lịch sử và thu hồi theme đã duyệt.
- Điểm uy tín Nhà sáng tạo tự cộng/trừ.
- Chuông thông báo trực tiếp cho người đăng.
- Theme bị từ chối/thu hồi có thể sửa thông tin và gửi lại từ Hồ sơ.

## Cài đặt
1. Chạy `SUPABASE_V3_8_0_REVIEW_SYSTEM.sql` sau SQL v3.7.0.
2. Chép patch vào source và build GitHub Actions.
