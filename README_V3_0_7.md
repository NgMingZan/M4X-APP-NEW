# M4X Theme v3.0.7

- Khôi phục M4X WEB với 3 tác vụ mặc định.
- Admin đổi link hoặc tắt từng tác vụ online qua Supabase.
- Khi mở web, app ẩn toàn bộ thanh trên/dưới và không hiện địa chỉ URL.
- Nút Back của Android quay lại trang trước; khi hết lịch sử sẽ đóng trình duyệt và trở về app.
- Tác vụ 18+ có hộp xác nhận đủ 18 tuổi.
