# M4X Theme v3.8.4 — Theme Video Style

## Thay đổi
- Đổi phần theme sang giao diện giống video mẫu.
- Danh sách theme hiển thị dạng lưới 3 cột, thẻ cao như poster.
- Trang chi tiết nền đen, ảnh preview vuốt ngang kiểu thư viện chủ đề.
- Thêm mục **Tác giả** trong trang chi tiết.
- Nút thao tác dưới cùng được làm lại theo kiểu video.
- Luồng giữ nguyên: xem chi tiết → mua bằng M4X coin → tải theme.
- Không cần SQL mới.
